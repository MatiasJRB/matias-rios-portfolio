# Contributing

This is a personal portfolio, so changes to biography, resume facts, imagery or
branding remain at the owner's discretion. Focus contributions on reproducible
bugs, accessibility, performance, security and documentation.

1. Fork the repository and create a focused branch.
2. Do not commit credentials, personal documents or generated build output.
3. Run `npm ci`, `npm run lint`, `npm run typecheck` and `npm run build`.
4. Open a pull request describing the problem and the behavior you verified.

For security issues, follow [SECURITY.md](SECURITY.md) instead of opening a
public issue.
